# 侯氏韧性企业模型评估 · 班组互评

- `index.html` 学员打分页（手机打开，选自己→给自己和其他人打分→自动提交到 Google 表格）
- `admin.html` 组织者后台（名单、链接、二维码、从 Google 表格拉取提交、对照图、导出图片）
- `GoogleAppsScript.gs` 粘到 Google 表格的 Apps Script 里，部署为 Web 应用后即为后端

## 组织者设置（一次，约 5 分钟）
1. 新建一个 Google 表格 → 菜单「扩展程序」→「Apps Script」。
2. 删除编辑器里的默认代码，把 `GoogleAppsScript.gs` 的全部内容粘贴进去，Ctrl/⌘+S 保存。
3. 右上角「部署」→「新建部署」→ 左侧齿轮选「Web 应用」：
   - 执行身份：我
   - 谁可以访问：任何人
   → 点「部署」，首次会要求授权，选择你的账号并允许。
4. 复制得到的「Web 应用网址」（以 `/exec` 结尾）。
5. 打开 `admin.html`（GitHub Pages 地址 + `/admin.html`），点「班组互评」，把网址粘到第 0 步，点「保存并测试」，显示“连接成功”即可。
6. 在第 1 步填名单，点「复制互评链接」，发到 Lark 群或投屏二维码。

## 课上
学员打开链接 → 选自己 → 打分 → 「生成互评码」→ 页面显示“已提交成功”。
后台每 20 秒自动拉取，也可点「拉取云端提交」。点开任何一人即出图，可「导出图片」；列表页可「导出全员合图」。
若某位学员自动提交失败，让他把页面上的整段文字发到群里，在后台第 2 步粘贴导入即可。
