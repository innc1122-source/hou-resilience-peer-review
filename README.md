# 侯氏韧性企业模型评估 · 班组互评

唯一入口：**https://innc1122-source.github.io/hou-resilience-peer-review/**

- 组织者直接打开这个网址 → 后台（流程面板：表格 → 名单 → 学员链接 → 收到提交 → 结果）。
- 从后台复制出的「学员链接」→ 学员手机打开即是打分页。
- 从后台复制出的「结果直播链接」→ 打开即是只读结果页，每 20 秒自动更新。

文件说明：`index.html` 入口分流；`admin.html` 后台；`rate.html` 学员打分页；`GoogleAppsScript.gs` Google 表格后端脚本。

## 一次性设置（约 5 分钟）
1. 新建 Google 表格 → 扩展程序 → Apps Script，删掉默认代码，粘入 `GoogleAppsScript.gs` 全部内容，保存。
2. 部署 → 新建部署 → 类型「Web 应用」→ 执行身份「我」→ 访问权限「任何人」→ 部署，首次需授权。
3. 复制以 `/exec` 结尾的 Web 应用网址。
4. 打开入口网址 → 流程面板第 1 步「设置」→ 粘入网址 → 「保存并测试」。

## 每次课
1. 第 2 步填名单；第 3 步「复制链接」发到 Lark 群，或点「二维码」投屏。
2. 学员打开 → 选自己 → 依次打分 → 「提交」，看到“提交成功”即完成。
3. 第 4 步显示“已收 n / N”，每 20 秒自动更新，也可「立即拉取」。
4. 点开任何一人看对照图并「导出图片」；第 5 步可「复制直播链接」、「全员合图」或「全部图片 zip」（全员合图 + 全员总览 + 每人一张）。

## 备用
某位学员自动提交失败时，他的页面会给出“备用互评码”。让他把整段文字发到群里，在第 4 步「手工导入」里粘贴即可。
