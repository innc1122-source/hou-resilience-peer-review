# 侯氏韧性企业模型评估 · 班组互评

- `admin.html` 组织者后台：设置 Google 表格、名单与链接，自动汇总学员提交，查看自评/他评对照图，导出图片。
- `index.html` 学员页：手机打开链接，选自己的名字，给自己和其他人打分，点“提交”即完成。
- `GoogleAppsScript.gs` 后端脚本：粘到 Google 表格的 Apps Script 里并部署为 Web 应用。

## 一次性设置（约 5 分钟）
1. 新建 Google 表格 → 扩展程序 → Apps Script，删掉默认代码，粘入 `GoogleAppsScript.gs` 全部内容，保存。
2. 部署 → 新建部署 → 类型「Web 应用」→ 执行身份「我」→ 访问权限「任何人」→ 部署，首次需授权。
3. 复制以 `/exec` 结尾的 Web 应用网址。
4. 打开后台 `admin.html` → 「班组互评」→ 第 1 步粘入网址 → 「保存并测试」，显示“连接成功”。

## 每次课
1. 后台「班组互评」第 2 步填名单，「复制互评链接」，发到 Lark 群或投屏二维码。
2. 学员打开链接 → 选自己 → 依次打分 → 「提交」，看到“提交成功”即完成。
3. 后台每 20 秒自动拉取，也可点「拉取提交」，按钮显示“已收 n/N”。
4. 点开任何一人查看对照图与差距解读，「导出图片」；列表页「导出全员合图」。

## 备用
某位学员自动提交失败时，他的页面会给出“备用互评码”。让他把整段文字发到群里，在后台第 3 步粘贴导入即可。
